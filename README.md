# BlueCalx

Experiments in generative music and live coding with [Strudel](https://strudel.cc).

This repository is where I explore algorithmic composition, evolving textures, rhythmic systems and sample manipulation. Most sketches begin as small experiments before growing into larger pieces.

## Current interests

- Generative ambient and minimal techno
- Jungle-inspired break manipulation
- Live coding workflows with Strudel
- Building reusable musical systems rather than fixed compositions
- Custom sample libraries and field recordings

## Influences

Some of the artists and creators inspiring this project:

- GAS
- The Field
- Deepchord
- Brian Eno
- Steve Reich
- Aphex Twin
- Switch Angel
- TodePond

## Philosophy

I'm interested in code as a creative medium. Rather than sequencing every note, I enjoy building systems that evolve over time—balancing structure with randomness to create music that is different every time it runs.

This repository is a sketchbook, not a finished album. Expect experiments, half-finished ideas and occasional discoveries.
